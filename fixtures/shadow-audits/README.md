# Fixtures locales para shadow audit

Los archivos JSON de esta carpeta son entradas locales del runner read-only y estan ignorados por Git. No deben contener secretos, emails ni credenciales.

`snapshot_profesorado_ingles_anon.json` se genera localmente desde una fixture institucional sintetica y anonimizada. Sirve para validar el circuito del runner, pero no reemplaza una exportacion anonimizada del snapshot real.
