# Documentos legales — borradores

Este directorio contiene borradores preparados a partir de las funciones actualmente implementadas en Institutional Hub:

- `TERMINOS_Y_CONDICIONES_BORRADOR.md`
- `POLITICA_DE_PRIVACIDAD_BORRADOR.md`

No están listos para publicación. Antes de enviarlos al abogado se deben resolver, como mínimo, los siguientes campos:

1. identidad legal, CUIT/CUIL y domicilio del proveedor;
2. marca y dominio definitivos;
3. emails de soporte, seguridad y privacidad;
4. modalidad comercial externa a la Plataforma, renovaciones y cancelación;
5. nivel de servicio y política de respaldos;
6. período de exportación y eliminación al finalizar el contrato;
7. región de Supabase, alojamiento y demás subencargados;
8. transferencias internacionales;
9. plazos de conservación por categoría;
10. jurisdicción contractual; y
11. código de responsable y bases inscriptas ante la AAIP.

## Recomendaciones previas al lanzamiento

- Sustituir el DNI como contraseña inicial por un enlace de activación o una credencial aleatoria de un solo uso.
- Exigir cambio de contraseña en el primer acceso.
- Preparar un Acuerdo de Tratamiento de Datos con cada institución.
- Incorporar un aviso breve de privacidad al crear o importar cuentas.
- Implementar aceptación y versionado de Términos y Política.
- Definir y automatizar retención, exportación y eliminación.
- Mantener una lista pública de subencargados.
- Revisar la inscripción de las bases ante el Registro Nacional de Bases de Datos Personales.
